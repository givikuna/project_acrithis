# Security Policy

## Reporting a Vulnerability

If you find a vulnerability in this project, please report it.

### Private Disclosure (Preferred):

Email me at **gvtsvariani@gmail.com**

### Public Disclosure

If this is safe to show up on GitHub issues, go ahead.

A "safe" vulnerability to show here would be anything that an attacker cannot yet directly use (say an LLM having a capability of running an unimportant program).

Anything allowing for privilege escalation, remote code execution, leaked secrets, outdated packages with known CVEs, or similar things are **DANGEROUS** and should be disclosed privately.

Otherwise, please do **NOT** do that.
Obviously.

If you're unsure of if something is "safe" enough, simply email me.

## What Constitutes a Security Issue?

Remote code execution
Plaintext secrets
Privilege escalations
Weak permissions
Insecure service configs
Outdated packages with known CVEs
Logging leaks
etc...
