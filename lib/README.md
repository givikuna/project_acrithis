# Acrithis Library

## acrithis_graph

`acrithis_graph` is an internal gleam library for creating graphs and trees for the Acrithis store.

Contains the data structures: `Tree`, `TreeNode`, `Graph`, `GraphVertex`.

More documentation in `acrithis_graph` folder.

## acrithis_base

`acrithis_base` is an internal gleam library containing base theorems, proofs, and axioms in lean4 and a gleam API for accessing them (and automatically placing them in the store).
